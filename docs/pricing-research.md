# Caribou PO - Pricing Research & Recommendation

*Research conducted: December 2025*

## Executive Summary

Based on competitive analysis of PO management, inventory management, and supplier management SaaS products, we recommend pricing Caribou PO at **$49-79/month** for small manufacturing and retail businesses.

---

## Market Analysis

### Inventory Management Software

| Price Range | Target Market |
|-------------|---------------|
| $25-100/month | Small businesses, basic features |
| $100-150/month | SMB with advanced features |
| $200-500/month | Mid-market, multi-location |
| $500+/month | Enterprise |

**Key findings:**
- Entry-level tools average ~$262/month
- Per-user pricing ranges from $18-150/user/month
- Cloud-based SMB solutions typically $25-100/month
- Free tiers common for very small operations

### Supplier Management Software

| Price Range | Features |
|-------------|----------|
| $50-500/user/month | Basic SRM (tracking, vendor lists) |
| $500-2000/user/month | Advanced analytics, automation, contract management |
| $500k+/year | Enterprise with full supply chain integration |

### Supply Chain / PO Management

- Entry-level SaaS: $10-135/user/month
- Most use per-user-per-month pricing model
- Tiered plans common based on features and transaction volume

## Caribou PO Value Proposition

### Unique Features
- **Yo-yo manufacturing specialization** - purpose-built for the industry
- **PDF generation** - factory-ready PO documents with product images
- **Pantone color matching** - color analysis and management
- **Engraving art tracking** - per-product art asset management
- **Production pipeline visualization** - at-a-glance order status
- **Retail inventory tracking** - multi-retailer inventory monitoring
- **Quote management** - production vs prototype quote tracking
- **CSV import** - bulk PO creation from existing workflows

### Target Customer
- Small yo-yo manufacturers
- Specialty retail businesses with manufacturing partnerships
- Companies managing 10-500 SKUs
- Teams of 1-10 users

## Pricing Rationale

1. **Below major competitors** - Undercuts Zoho paid ($39+), Katana ($399), Precoro ($499)
2. **Above commodity tools** - Premium over basic inventory trackers ($25)
3. **Value-based** - Specialized features justify premium over generic solutions
4. **Growth-friendly** - Room for enterprise tier as product matures
5. **SMB-accessible** - Affordable for small manufacturing businesses

## Launch Recommendations

### Pre-Launch Requirements
1. Fix critical security vulnerabilities (hardcoded credentials)
2. Add input validation to all API endpoints
3. Implement proper error handling
4. Add basic monitoring/logging

### Go-to-Market
1. Start with **$49/month single tier** for beta customers
2. Gather feedback on feature usage
3. Introduce tiered pricing based on actual usage patterns
4. Consider annual discount (15-20% off)

### Future Pricing Levers
- Per-location pricing for multi-warehouse
- Transaction volume tiers
- API access as premium feature
- White-label/custom branding tier
- Integration add-ons (QuickBooks, Shopify, etc.)
